# 产品与架构设计

状态：讨论稿；已确定的需求与尚待确定的选项分别记录。此文档不代表功能已实现。

## 目标与使用者

面向招聘方的自主浏览，以及候选人在面试中的主动讲解。首个实例以 AI Infra 为主、Coding Agent 为辅，围绕真实系统交付、当前项目和研究经历组织内容。

网站需要同时服务三种阅读深度：快速理解个人定位、按主线听完介绍、围绕某个问题深入查看证据。

## 两种使用方式

### 自由浏览

显示个人介绍、工作经历、精选项目、训练实践与研究、其他作品，以及简历和联系方式。支持通过名称、技术标签和状态查找项目，并访问独立详情链接。

### 面试导览

提供预设讲述顺序、上一章/下一步、章节跳转、键盘操作、进度提示与全屏。主线以约 7–8 分钟为设计起点，支持跳过章节和停留讲解，不自动推进。

技术细节展开后应保留章节和步骤位置，关闭后回到原处。图表、结果和证据可以在当前上下文中查看。

初步章节模板：

| 章节 | 讲述目的 | 呈现方式 |
| --- | --- | --- |
| 我是谁 | 方向与核心优势 | 个人形象、定位与能力摘要 |
| 我的经历 | 研究、工作与当前方向的联系 | 时间线与可展开的经历 |
| 工程案例一 | 问题、职责、架构与结果 | 场景、数据流、关键技术解释 |
| 工程案例二 | 资源管理与系统交付 | 处理管线、生命周期、结果 |
| 当前专业实践 | 已完成里程碑与后续方向 | 实验、项目架构、结果记录 |
| 辅助项目 | 补充系统设计和交付能力 | 精选项目与演示 |
| 岗位匹配 | 经验与目标工作的联系 | 能力、证据、联系方式 |

这些章节是初始模板，不是固定页面数。实际履历和具体项目通过内容层接入。

## 视觉与场景

参考 intro3d 的标签导航和镜头过渡。3D 主体尚待选择：个人形象加技术场景、围绕个人形象组织章节，或以技术场景为主。

人物与场景可以承担开场和章节过渡。技术内容需要清晰、稳定、可放大的图文区域。每个讲述步骤聚焦一个主要结论。

所有内容都必须能在没有 3D 的视图中阅读。尊重减少动态效果的偏好，提供明确的暂停或关闭动效方式。

新项目默认具有可用场景，不要求创建 3D 模型。专属场景属于可选增强。

## 内容模型

下列是逻辑模型，具体文件格式和字段将在实现前确定：

| 实体 | 主要信息 |
| --- | --- |
| Profile | 姓名、简介、方向、联系方式、简历入口 |
| Experience | 时间、组织、角色、职责、关联案例 |
| Project | 稳定 ID、名称、摘要、标签、状态、个人职责、内容块、素材与证据 |
| Research | 论文或研究名称、作者贡献、方法、实验、发表信息与链接 |
| Tour | 稳定 ID、标题、有序章节、各章节步骤与内容引用 |
| Scene | 稳定 ID、素材、默认视角、过渡配置、备用呈现 |
| Theme | 颜色、字体、间距、动效参数 |

一个项目可以关联多个演讲路线。内容、路线与场景通过 ID 关联，不依赖列表位置或显示名称。

项目完成状态与网站显示状态分开：例如“开发中/阶段实验完成/已发布版本”描述成果；“草稿/显示/隐藏/归档”描述网站可见性。状态词的精确集合待内容模型定稿。

## 可组合内容块

首版优先支持概述、职责、架构图、问题与方案、结果或指标、图片和证据链接。代码片段、交互时间线和演示视频按实际案例需要加入。

简单项目可以只使用部分内容块。增加一种内容块时集中扩展渲染组件，不为每个项目复制整套页面。

## 增删查改与引用一致性

- 新增：填写项目内容、添加素材、设置排序及是否进入精选和导览。
- 查询：按名称、标签、状态筛选。
- 修改：同一份内容的修改同步反映在浏览与导览中。
- 排序：项目列表顺序与某条导览路线的顺序分别配置。
- 隐藏和归档：显示状态决定相应入口是否可见，避免仍可从导览进入隐藏项目。
- 删除：检测相关路线和素材引用；存在悬空引用时给出具体位置，不生成空白章节。

首版内容源使用 Markdown 与结构化配置，纳入 Git。可视化内容编辑界面为后续选项，不预先引入账户系统、数据库或在线写入接口。

## 内容与证据

个人职责、已完成结果、实验环境和后续计划分开表达。指标需要说明测量范围和条件；项目的运行状态与公开代码版本应一致。

开源模板使用可公开、可复用的示例资料。个人履历与素材独立组织，原始求职资料不作为模板内容自动提交。

## 运行与交付要求

- 桌面和手机均能阅读，桌面屏幕共享时保持清晰。
- 键盘导航和焦点管理可用；展开细节后关闭时恢复焦点与位置。
- 主要内容预载，3D 不可用时仍能继续介绍。
- 静态备用视图是首版要求；完整离线安装和缓存策略另行验证，不预先承诺。
- 每个项目和章节具有稳定链接。
- 发布前检查页面、链接、图片、简历下载、移动端溢出和控制台错误。
- 本地开发与公开发布分别给出说明；生产使用持久链接。

## 核心验收场景

1. 新增项目只改内容与素材，不改页面组件；默认场景和导航可用。
2. 修改标题后，项目链接、路线引用和场景关联保持有效。
3. 同一项目在浏览和导览中使用一致文案。
4. 调整导览顺序不必复制或移动项目内容。
5. 隐藏、归档或删除项目后，不出现空白章节或失效的内部引用。
6. 展开技术细节并关闭后，返回原章节、原步骤。
7. 关闭 3D 和动画后，全部履历和讲述内容仍可使用。
