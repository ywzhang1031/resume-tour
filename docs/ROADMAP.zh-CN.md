# 开发计划

## 里程碑 0：需求与仓库

- [x] 记录面试导览和自由浏览需求。
- [x] 记录内容、路线、场景和主题分离的架构原则。
- [x] 记录项目增删查改和引用一致性要求。
- [x] 添加中英文项目介绍、贡献说明和 MIT License。
- [ ] 确定 3D 主体与首个案例分镜。

## 里程碑 1：首个可运行样板

- [ ] 确定技术栈与内容模型。
- [ ] 实现个人介绍与一个工程案例。
- [ ] 实现逐步讲解、章节导航和技术细节展开。
- [ ] 提供默认场景与无需 3D 的备用视图。
- [ ] 在桌面与手机检查可读性和操作方式。

## 里程碑 2：内容维护与完整履历

- [ ] 接入个人资料、经历、项目和研究内容。
- [ ] 实现名称、标签和状态筛选。
- [ ] 支持项目排序、隐藏和归档。
- [ ] 校验稳定 ID、素材路径和章节引用。
- [ ] 通过新增、改名、换序、隐藏和删除项目的验收场景。
- [ ] 提供示例内容及替换指南。

## 里程碑 3：面试可用与公开发布

- [ ] 完成键盘、全屏、进度和位置恢复。
- [ ] 检查减少动态效果偏好、3D 关闭和加载失败的处理。
- [ ] 验证主要内容预载及弱网情况下的备用方式。
- [ ] 校验公开履历、项目版本和指标说明。
- [ ] 检查生产 URL、手机视口、控制台、链接与简历下载。
- [ ] 补充安装、启动、内容维护、部署和贡献说明。
- [ ] 发布首个可运行版本。

## 后续选项

根据真实使用反馈决定是否增加可视化编辑、多条岗位定向导览、更多场景、完整离线缓存或内容导出。未进入里程碑的选项不视作首版承诺。
