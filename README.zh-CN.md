# Resume Tour

用于面试讲解与日常求职展示的开源个人网站项目。

[English](README.md) · [产品与架构设计](docs/DESIGN.zh-CN.md) · [开发计划](docs/ROADMAP.zh-CN.md)

## 当前状态

**方案阶段。** 当前仓库保存已讨论的需求、架构原则与开发计划，尚未实现可运行网站，也没有部署演示。以下功能均为规划内容。

## 要解决的问题

面试时打开一个网站，就能按顺序介绍自己、工作经历、项目和研究；面试官追问时，可以展开架构、技术取舍和实验依据，讲完返回主线。平时，同一个网站也能供招聘方自行浏览和下载简历。

首个使用场景是 AI Infra 求职，Coding Agent 为辅助方向。网站的内容结构应能被其他使用者替换和复用。

## 计划提供

- 自由浏览与面试导览共用一份内容。
- 章节目录、逐步讲解、键盘操作、进度提示与全屏。
- 可选的 3D 人物或技术场景，以及清晰稳定的技术图文。
- 架构图放大、技术细节展开、项目演示与证据入口。
- 项目的新增、查询、修改、排序、隐藏和归档。
- 内容、演讲路线、视觉主题与场景独立维护。
- 关闭 3D 或减少动效后仍能完整使用的备用视图。

## 维护方式

首版使用 Markdown 和结构化配置管理内容，并通过 Git 保存变更历史。新增项目应只需要填写资料、加入素材和设置展示位置，不需要修改页面组件或重新制作 3D 场景。

项目通过稳定 ID 与章节、场景关联。没有专属场景的新项目使用默认场景。未来可视化编辑界面复用相同内容格式；首版不默认加入在线管理后台。

技术框架、精确字段格式和 3D 主体尚待确定，详见[设计文档](docs/DESIGN.zh-CN.md)。

## 参考与复用

参考 [intro3d](https://intro3d.com/) 的章节导览和镜头过渡方式，自行实现适合技术面试的内容布局与交互。项目采用 [MIT License](LICENSE)；第三方素材和个人资料的使用范围另行标注。

参与方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。首个可运行版本完成后会补充本地开发、内容修改和部署说明。
